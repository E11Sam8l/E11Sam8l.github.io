# 把 Markdown 变成可发布的网站

V1 的目标是让内容维护保持简单：文件放在 `docs/`，本地运行 VuePress 检查效果，提交到 GitHub 后由 Actions 构建并发布到 Pages。

## 这套流程的优点

内容和配置分开，主题负责导航、目录、搜索和响应式布局，作者只需要持续维护 Markdown。

## 下一步

后续可以逐步加入真实的知识主题、项目链接和图片资源，而不必先改动集合配置。
