# 实践记录

## 实践目标

说明本次实践需要验证的想法或需要完成的任务。

## 实践步骤

1. 准备输入、资料或运行环境。
2. 按步骤记录操作过程和关键参数。
3. 检查结果并与预期进行比较。

### 代码与示例

按需使用带语言标记的代码块记录示例：

```ts
const projectName = '项目名称'
console.log(projectName)
```

### 图片与附件

将图片放入项目的 `assets/` 目录，再用相对路径引用。例如，添加 `assets/example.png` 后可以写：

```md
![实践结果](./assets/example.png)
```

## 结果与问题

记录观察到的结果、遇到的问题及处理方法。

## 下一步

列出需要继续验证或完善的内容。
